# Catcher

Monorepo for Catcher: 24/7 call answering and intake for personal-injury firms.

```
apps/
  lander/             catchersolutions.com — PI firms: lander, apply form, confirmation page, /api/lead
  lander-foundation/  same lander for foundation contractors (not deployed yet)
packages/      shared code (empty for now)
tools/         repo scripts
```

Add new projects (CRM, more landers, website, client work) as folders under `apps/`, and
shared code under `packages/`. npm workspaces pick both up.

## apps/lander

Plain HTML, no build step. Vercel serves the files and runs `api/lead.js` as a function.

- `index.html` — the lander. "Start signing cases" opens the apply form (also reachable at `/#apply`).
- `confirmation/` — where the form lands after the last step.
- `privacy/`, `terms/` — legal pages, generated by `python3 tools/build-lander-pages.py`
  together with `confirmation/`. Edit the script, then rerun it.
- `api/lead.js` — emails each lead through Resend: once after step 1 (contact details) and
  again with every answer when the form is finished.

### Environment (Vercel → Project → Settings → Environment Variables)

| Name | Value |
| --- | --- |
| `RESEND_API_KEY` | Resend API key |
| `LEAD_TO` | where leads are emailed; comma-separate several |
| `LEAD_FROM` | sender. Until `catchersolutions.com` is verified in Resend, leave unset: Resend's test sender (`onboarding@resend.dev`) only delivers to the Resend account's own email |

### Deploy

The Vercel project `catcher-lander` has Root Directory `apps/lander` and deploys on every push to `main`.
